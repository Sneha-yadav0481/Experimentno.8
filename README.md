Aim: implement re module in python

Algorithm

Step 1: Start the program.

Step 2: Import the re module to use regular expressions.

Step 3: Get an email address or mobile number from the user.

Step 4: Define a regular expression pattern for email validation.

Step 5: Define another regular expression pattern to check whether the mobile number contains exactly 10 digits.

Step 6: Use re.fullmatch() to check whether the entered data matches the email pattern.

Step 7: If the input matches the email pattern, display "Valid email".

Step 8: Otherwise, check whether the input matches the mobile number pattern.

Step 9: If the input matches the mobile number pattern, display "Valid phone number".

Step 10: If neither condition is satisfied, display "Invalid input".

Step 11: Stop the program.
